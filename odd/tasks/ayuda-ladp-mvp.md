# AYUDA LADP .com — MVP (Fenómeno El Niño / DINAPROS)

## Objective

Deliver a production-shaped MVP of the AYUDA LADP humanitarian alert system: role-based incident
capture (Asistente), area supervision (Coordinador) and national executive KPIs (Jefatura), with
free browser GPS, image-free CSV export, offline-tolerant local persistence, and a Vitest suite above
80% coverage plus a Playwright flow that records video.

## Problem / Why

During El Niño emergencies brigades lose signal in the field and hundreds of reports arrive at the same
time. The system must never mint duplicate audit codes, must keep drafts locally, must validate data
before touching the database, and must give Jefatura a national picture in seconds.

## Scope

In scope:

- Clean Architecture split: `domain` / `application` / `infrastructure` / `presentation`.
- Zod validation of every incident field (no negative or decimal households, no future date).
- Audit code `INC-YYYY-NNNNN` generated by a single atomic allocator.
- Duplicate/existence check by centro poblado before saving.
- Free GPS through `navigator.geolocation` (no API key, no paid provider).
- CSV export without images, BOM + CRLF, quoted fields.
- Local-first persistence (localStorage) seeded with demo data so the MVP runs with zero cloud setup.
- Supabase-ready PostgreSQL DDL: enums, sequence + trigger, RLS policies, B-Tree/GIN indexes.
- Login screen, three role views, floating support chat, QA "break the module" bar.
- Unit/RTL tests >= 80% coverage, Playwright E2E with `video: 'on'`.

Out of scope (documented in README):

- A live Supabase project. No credentials exist in this environment, so runtime uses the local
  repository adapter; the SQL DDL and a `VITE`-free env switch are shipped for connection later.
- Real password hashing/IdP. Demo credential check through the auth port.

## Constraints

- Next.js 15 App Router, React 19, TypeScript strict, Tailwind CSS v4, lucide-react only (no images).
- Dates evaluated in `America/Lima`. Server and client must not disagree.
- The app must build and run with `npm run dev` on a clean machine with no env vars.
- Repo is greenfield: `C:\Users\elcra\Desktop\ONG` (own git repo, branch `feat/ayuda-ladp-mvp`).
